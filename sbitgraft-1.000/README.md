# sbitgraft

本项目只用它的一个模式：`--strip`，把字体里的 hinting 去掉。

hinting 占成品体积的四成左右，而它的收益集中在 12px 及以下的密集汉字上。只在
16px 以上用字、或者要把字体嵌进文档而在意体积的人，有理由把它去掉，不必在「带」
与「不带」两个下载之间选。

## 编译

```sh
make
```

需要一个 C99 编译器，无其他依赖。

## 用法

```sh
sbitgraft --strip GlowHei-GBK.ttc GlowHei-GBK-nohint.ttc
```

单个 TTF 与 collection 都能读。collection 的每一款都会处理，输出仍是 collection。

删掉的是 `fpgm`、`prep`、`cvt ` 三张表与每个字形的指令块，并把 `maxp` 中为解释器
保留的字段清零（`maxZones` 置 1，其余置 0）。`maxp` 必须一并处理，光栅器按那些数
字分配栈与存储空间，若它们仍描述一个已不存在的解释器，校验工具会报错。

简单字形与复合字形都处理。复合字形的指令块位于最后一个组件之后，需逐个跨过组件
才能定位。`gasp` 不在删除之列，它描述的是渲染方式而非网格对齐，没有 hinting 的
字体同样需要。

轮廓、度量、字符映射与命名都不会被改动。

## 另外两个模式与本字体无关

这个工具原本是为另一款带内嵌点阵的字体写的，因此还有 `--mono`（移植点阵并标记等
宽）与 `--pack`（把若干 TTF 装进 collection）两个模式。本字体没有内嵌点阵，产物
也已是 collection，两者都用不上。留着是为了与上游同一份源码，改动只需做一次。
